# Código de Conducta

## Nuestro compromiso

Nosotros, mantenedores y colaboradores de **MyFBox**, nos comprometemos a hacer que la participación en el proyecto sea una experiencia libre de acoso para todas las personas, independientemente de su edad, tamaño corporal, discapacidad, etnia, identidad y expresión de género, nivel de experiencia, nacionalidad, apariencia personal, raza, religión o identidad y orientación sexual.

## Comportamientos esperados

- Usar un lenguaje acogedor, respetuoso y objetivo.
- Aceptar críticas constructivas con enfoque técnico.
- Priorizar lo que es mejor para la comunidad y para la seguridad de los usuarios del proyecto.
- Demostrar empatía hacia otros participantes.

## Comportamientos inaceptables

- Comentarios despectivos, insultos o ataques personales/políticos.
- Acoso público o privado.
- Publicación de información privada de terceros sin consentimiento explícito.
- Cualquier conducta incompatible con un entorno profesional y colaborativo.

## Aplicación

Los mantenedores son responsables de aclarar los estándares de comportamiento aceptable y pueden eliminar, editar o rechazar comentarios, commits, issues y Pull Requests que no estén alineados con este Código de Conducta, así como expulsar temporal o permanentemente a participantes en casos graves o reincidentes.

Para reportar infracciones, contacta de forma privada con los mantenedores a través de los canales del repositorio en GitHub.
