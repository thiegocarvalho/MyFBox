# 行为准则

## 我们的承诺

作为 **MyFBox** 的维护者与贡献者，我们承诺让所有人的参与都成为无骚扰的体验，无论年龄、体型、残障、族裔、性别认同与表达、经验水平、国籍、外貌、种族、宗教信仰或性认同与性取向如何。

## 期望的行为

- 使用友善、尊重且客观的语言。
- 接受以技术为核心的建设性批评。
- 优先考虑对社区及项目用户安全最有利的方案。
- 对其他参与者抱有同理心。

## 不可接受的行为

- 贬损性评论、侮辱或人身/政治攻击。
- 公开或私下的骚扰行为。
- 未经明确许可公开他人的私人信息。
- 任何不符合专业、协作环境的行为。

## 执行

维护者有责任阐明可接受行为的标准，并可移除、编辑或拒绝不符合本行为准则的评论、提交、Issue 和 Pull Request，在严重或屡次违规的情况下可暂时或永久封禁相关参与者。

如需举报违规行为，请通过 GitHub 仓库的私密渠道联系维护者。
